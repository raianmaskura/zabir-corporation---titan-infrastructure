> **Tier-One Civil Engineering, Sovereign Procurement & Heavy Infrastructure Consultancy across South Asia.**

Zabir Corporation is an institutional-grade civil engineering consultancy and heavy infrastructure delivery advisory platform. Engineered for sovereign ministries, bilateral development institutions (World Bank, ADB, JICA), and premier EPC joint ventures.

---

## 🏛️ Core Engineering Sectors

- **Heavy Civil & Structural Engineering**: Finite element stress modeling, Code-F airfield taxiways, high-density apron hardstands, and post-tensioned viaducts.
- **Geotechnical & Subsurface Consolidation**: Deep rotary bentonite slurry bored piling, CPTu piezocone penetration testing, and Prefabricated Vertical Drains (PVD) consolidation.
- **Hydrology, River Training & Coastal Defense**: 2D/3D flood routing, hydrodynamic scour depth simulation, and Category-5 cyclonic surge revetments.
- **Mass Transit & Elevated Corridors**: Precast segmental box girder erection, lead-rubber seismic bearings, and ballastless track slab tolerances.
- **Industrial Special Economic Zones (SEZs)**: Coastal marine defense, hydraulic sand dredging, 132kV dual-circuit primary substations, and industrial WWTP.
- **High-Pressure Energy & SCADA Telemetry**: Cross-country gas transmission pipelines, horizontal directional drilling (HDD), and SIL-3 telemetry backbones.

## 🚀 Key Features & Interactive Demos

- **Executive Dossier Viewer**: Interactive technical dossiers for landmark projects (Dhaka Airport Terminal Expansion, Mass Transit Line 6, Chattogram SEZ Marine Defense, CWASA Trunk Sewerage, National Gas SCADA).
- **Formal RFQ & Tender Dispatch System**: Encrypted submission portal generating verifiable tracking references (`ZBR-2026-TNDR-XXX`).
- **Interactive Engineering Scope Matrix**: Multi-sector inquiry submission for technical terms of reference (ToR).
- **Corporate Heritage Timeline**: Three decades of sovereign civil infrastructure milestones (1994–2026).
- **Executive Technical Bulletins**: Field research case studies and compliance whitepapers.
- **Polished Presentation UI**: High-contrast, executive-scale typography with seamless transitions, responsive layouts, and accessible color hierarchy.

## 🛠️ Tech Stack & Architecture

- **Frontend**: React 19, TypeScript
- **Styling**: Tailwind CSS v4 with bespoke sovereign design tokens (`Space Grotesk` display typography and `IBM Plex Sans` body typography)
- **Icons**: Google Material Symbols Outlined
- **Build Tool**: Vite 6 with `@tailwindcss/vite` and `@vitejs/plugin-react`

## 💻 Local Development

### Prerequisites
- Node.js (v18+ recommended)
- npm or pnpm

### Getting Started

```bash
# 1. Install dependencies
npm install

# 2. Launch Vite development server
npm run dev

# 3. Build for production preview
npm run build
npm run preview
```

The application runs locally on `http://localhost:3000`.
